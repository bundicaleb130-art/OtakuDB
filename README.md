# OtakuDB

OtakuDB is a PostgreSQL database project for storing and managing anime and manhwa information.

## Features

- PostgreSQL relational database
- 100,000+ media records
- Anime and manhwa data
- Ratings and release years
- Status tracking
- Watched-status tracking
- Duplicate prevention using UNIQUE constraints
- Python bulk importer
- AniList GraphQL API integration
- Pagination
- API retry handling

## Technologies

- Python
- PostgreSQL
- SQL
- GraphQL
- AniList API
- Git
- GitHub
- Ubuntu Linux
